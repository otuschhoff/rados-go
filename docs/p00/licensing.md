# Licensing and Provenance Decision

Decision for P00: **do not choose a distributable project license yet**. The
implementation will be independently written from documented protocol facts,
observations and small cited source facts. No Ceph source is copied or translated
into the shipped module until file-level review determines obligations and the
project license is approved by a human owner.

The pinned Ceph `COPYING` file states a default of LGPL-2.1 or LGPL-3 and assigns
different licenses to specific subtrees; `doc/*` is CC-BY-SA-3.0. The public C
header carries an LGPL-2.1 notice. This prevents a blanket assumption that all
consulted protocol material has one license.

| Component | Treatment | Distribution |
| --- | --- | --- |
| Generated API inventory | Facts extracted from public declarations; signature text retained for traceability | Review before release because signatures originate in LGPL-covered headers |
| P00 native oracle | Newly written test code linked to librados in isolated infrastructure | Not part of the Go module or production binary; source distribution obligations still apply |
| Future Go implementation | Independent implementation, with per-file provenance records | License remains undecided pending legal/human review |
| Binary fixtures | Generated by pinned tools and tagged with source/tool/version | Review redistribution per fixture before commit |
| Ceph containers/tools | Referenced by immutable digest; not redistributed by this repository | Governed by upstream image/package licenses |

Every future protocol task must record `independent`, `adapted`, or `ported`, the
exact upstream paths and commit, and applicable notices. Direct translation is a
stop condition until licensing is resolved.
